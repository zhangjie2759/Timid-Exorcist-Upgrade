GAME-003 食材料理灰盒说明：
- 本版本只验证玩法闭环，继续复用现有妖怪、小动物和 Canvas 画面，没有补正式食材或厨房美术。
- 成功封印妖怪有概率获得幻想食材；每局默认 1 张“封鲜符”，点亮后下次成功封印保证获得食材。
- 闯关中点击“主页”视为见好就收，本局食材安全带回；失败会丢失本局未结算食材。
- 原“灵宠屋”入口改为“厨房”，包含“灶台”和“小厨师队”两个页面。
- 灶台可以用炒锅或蒸笼自由组合食材；失败实验也会消耗食材。
- 首次成功料理永久加入食谱，料理自动出售获得铜钱。
- 铜钱可购买最多两个今日技能；技能按本地自然日 00:00 清空，食谱和铜钱永久保留。
- 小厨师队暂时保留旧灵宠数据和功能，后续再逐步转换成动物厨师团队。

当前灰盒食材：朱焰番茄、金羽蛋、云纹米、月泉水。
当前灰盒料理：赤焰番茄炒金羽蛋、金羽蛋炒云纹米、月泉金羽蒸蛋、云纹月泉米糕。

使用方法：
1. 解压 zip。
2. 把 index.html、game.js、images 文件夹整体上传到 GitHub 仓库根目录。
3. 覆盖原来的同名文件。
4. GitHub Pages 更新后强制刷新浏览器。

本版重点：
- 新增“灵宠屋”：遇到指定小动物并安全通过后，可以结缘灵宠。
- 首批灵宠：兔子、小狗、猫头鹰。
- 灵宠会通过重复结缘获得经验，并在 2 级、3 级出现明显外观变化。
- 开局前可以选择 1 只灵宠出战。
- 兔子提供危急自动关门，小狗提供遇鬼预警，猫头鹰提供隔门异常感知。
- 通过房间会获得灵火，成功封印会获得符纸碎片，为后续经营系统继续扩展预留。
- 结算页新增本局收获、灵宠经验、进化提示，并可直接前往灵宠屋。
- 灵宠屋新增成长条、下一形态预览和更明显的出战标识。
- 兔子、小狗、猫头鹰的技能触发都有独立的 canvas 特效反馈。
- 封印成功后，门上会浮现朱砂红笔画出的妖怪形态和名字，像直接写在木门上的封印痕迹。
- 前几门危险增长放缓，小动物通过停留时间加长，方便新玩家理解规则。
- 图鉴仍记录见过的鬼和小动物；妖怪 Boss 进化系统保留。
