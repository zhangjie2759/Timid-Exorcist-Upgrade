下一间 / 胆小除魔师 v0.12.1_corridor_assets

这个包包含：
- index.html
- game.js
- images/room/墙.png、房间.png、门.png、门框.png
- images/鬼/ 全部山海经鬼素材
- images/小动物/ 全部安全小动物素材
- images/鬼火/ 鬼火素材
- images/封印按钮.png

使用方法：
1. 解压 zip。
2. 把 index.html、game.js、images 文件夹整体上传到 GitHub 仓库根目录。
3. 覆盖原来的同名文件。
4. GitHub Pages 更新后强制刷新浏览器。

本版重点：
- 小动物替代原来的“1号人物”等安全角色。
- 鬼素材调用 images/鬼/ 文件夹。
- 鬼火素材调用 images/鬼火/ 文件夹。
- 房间、墙、门、门框调用 images/room/ 文件夹。
- 空间逻辑为无限长廊：开完一扇门，当前门位横向滑走，下一扇门滑入。
