胆小除魔师升级版 v0.19.0_kitchen_flow_loadout_chefs

当前灰盒闭环：
1. 巡夜开门，判断门后是妖怪、小动物还是空房。
2. 成功封印妖怪有概率获得幻想食材；封鲜符可保证一次掉落。
3. 局内点击“收工”可安全带回食材；失败会失去本局未结算食材，携带保鲜背包时保住一份。
4. 厨房测试食材每种自动补到 99 份。料理台默认开放三格，可拖拽或轻点放入食材。
5. 选择“炒”或“蒸”后开始料理；成品先进入出餐台，出售是独立操作。
6. 当前有四道双食材料理、三道三食材料理；失败实验会消耗食材并生成黑暗料理。
7. 铜钱在今日技能商店购买技能。技能当天拥有、当地时间 00:00 清空。
8. 每次巡夜前进入“出发准备”，从今日拥有技能中选择最多 3 个本局携带。
9. 小动物不进入巡夜、不提供局内效果。兔子、小狗、猫头鹰作为厨房队伍累计，统一佩戴厨师帽，不设等级、经验或进化形态。
10. 旧妖变二选一系统、灵宠出战与动物局内特效已经从当前流程和代码中移除；妖怪仍随门数自然增强。

当前食材：
- 朱焰番茄（西红柿）
- 金羽蛋（鸡蛋）
- 云纹米（大米）
- 月泉水（清水）

三食材料理：
- 朱焰番茄 + 金羽蛋 + 云纹米，炒：赤焰番茄金羽蛋炒饭
- 朱焰番茄 + 金羽蛋 + 月泉水，蒸：月泉番茄蒸金羽蛋
- 金羽蛋 + 云纹米 + 月泉水，蒸：金羽云纹蒸米糕
